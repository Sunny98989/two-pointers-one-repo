# C Programming — Quick Reference

A simple reference for writing, compiling, and running C programs on macOS using Apple's Clang compiler.

## 1. Prerequisites

Check whether Clang is installed:

```bash
clang --version
```

If it's not installed, install Apple's Command Line Tools:

```bash
xcode-select --install
```

## 2. Compile and Run C Programs

Suppose your C file is named `hello_world.c`.

### Recommended command

```bash
clang -std=c11 -Wall -Wextra hello_world.c -o hello_world && ./hello_world
```

This command:
- Compiles the C source file.
- Uses the C11 standard.
- Enables compiler warnings.
- Creates an executable named `hello_world`.
- Runs the executable if compilation succeeds.

### Basic compilation

```bash
clang hello_world.c -o hello_world
```

### Execute separately

```bash
./hello_world
```

### Compile and execute in one go

```bash
clang hello_world.c -o hello_world && ./hello_world
```

### Without specifying an executable name

```bash
clang hello_world.c && ./a.out
```

`a.out` is the default executable name generated by Clang.

## 3. Useful Compilation Commands

| Command | Purpose |
|---|---|
| `clang file.c -o output` | Compile with a custom executable name |
| `clang -std=c11 file.c -o output` | Compile using C11 |
| `clang -std=c17 file.c -o output` | Compile using C17 |
| `clang -Wall file.c -o output` | Enable common warnings |
| `clang -Wextra file.c -o output` | Enable additional warnings |
| `clang -g file.c -o output` | Include debugging information |
| `clang -O2 file.c -o output` | Enable optimizations |
| `clang -Wall -Wextra -Werror file.c -o output` | Treat warnings as errors |

You can combine multiple flags:

```bash
clang -std=c11 -Wall -Wextra -g file.c -o output
```

|---|---|
| `pwd` | Display current directory |
| `ls` | List files and folders |
| `ls -la` | List all files, including hidden files |
| `cd folder` | Navigate into a folder |

| `clear` | Clear terminal |
| `mkdir folder` | Create a directory |

| `rm file` | Delete a file |
| `./program` | Execute a compiled program |

## 5. Multiple C Files

If your project contains multiple C source files:

```bash
clang -std=c11 main.c functions.c -o program && ./program
```

Clang compiles and links both source files into one executable.

## 6. Check Compiler Information

```bash
clang --version
```

Check the supported C language standards:

```bash
clang -std=c23 -dM -E -x c /dev/null
```

Note: C23 support depends on your installed Clang version.

## 7. Important Concepts

- **Source file (`.c`):** Contains your C code.
- **Compiler (Clang):** Translates C source code into machine code.
- **Executable:** The compiled program that your Mac can run.
- **`-o`:** Specifies the name of the output executable.
- **`&&`:** Executes the next command only if the previous command succeeds.
- **`./`:** Runs an executable from the current directory.
- **`a.out`:** Default executable filename when `-o` isn't specified.

## 8. Recommended Workflow

For everyday C programming practice:

1. Create a `.c` file.
2. Write your C program.
3. Open the VS Code integrated terminal.
4. Run:

```bash
clang -std=c11 -Wall -Wextra main.c -o main && ./main
```

5. Modify your code and repeat.

**Happy Coding!** 🚀
